# Smaczna Uczta — Strona Firmy Cateringowej

Jednopodstronicowa strona internetowa dla fikcyjnej firmy cateringowej **Smaczna Uczta** z Warszawy.

## Technologie

- [Astro 5](https://astro.build/) — framework
- [Tailwind CSS 4](https://tailwindcss.com/) — stylowanie (via `@tailwindcss/vite`)
- Google Fonts: DM Serif Display + DM Sans

## Sekcje

1. **Nawigacja** — stała, z efektem przewijania i mobilnym menu
2. **Hero** — pełnoekranowy, ze zdjęciem jedzenia i statystykami
3. **O nas** — historia firmy, wartości, kolaż zdjęć
4. **Oferta** — 4 karty usług z cenami
5. **Menu** — przystawki, dania główne, desery, pakiety
6. **Formularz** — zapytanie o wycenę
7. **Opinie** — 4 opinie klientów
8. **Kontakt** — dane kontaktowe + mapa OpenStreetMap
9. **Stopka** — linki, dane, credit

## Uruchomienie

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
